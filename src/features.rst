########
Features
########

TurboGears lets you choose the structure and capabilities your application
needs, from a single-file service to a full-stack project.

Web Applications and APIs
=========================

Controllers expose Python methods as web endpoints. Templates render HTML;
JSON responses support APIs (application programming interfaces). The API
quickstart adds parameter validation, an OpenAPI specification (a description
of your API for tools), interactive documentation and authentication.

Persistence and Authentication
==============================

Full-stack quickstarts include SQLAlchemy, an object-relational mapper for
working with databases through Python models. Transaction management,
authentication and permissions support database-backed applications;
development tools include Alembic database migrations.

Project-Aware Development
=========================

Gearbox, the command-line toolkit, creates projects and scaffolds, serves the
application and opens an application-aware shell. Generated projects include
tests, development configuration and ``AGENTS.md`` instructions for coding
assistants. Optional agent skills and structured inspection help developers
and assistants work with the same project conventions.
