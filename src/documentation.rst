#############
Documentation
#############

Choose a guide for the application you want to build:

- `Minimal-mode tutorial`_ — a single-file application and installation.
- `Web application quickstart`_ — create a project with Gearbox, the command-line toolkit.
- `Building a JSON API`_ — build a JSON API with ``gearbox quickstart-api``, automatic OpenAPI, and validation.
- `Agent Tooling`_ — work with coding assistants using project instructions and development tools.
- `Agentic Development Walkthrough`_ — complete tutorial developing a feature guided by a coding agent.
- `The CogBin`_ — explore community pluggable applications, extensions, and widgets.

For complete reference, browse the `TurboGears Documentation`_.
