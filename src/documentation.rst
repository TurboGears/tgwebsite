#############
Documentation
#############

Choose a guide for the application you want to build:

- `Minimal-mode tutorial`_ — a single-file application and installation.
- `Web application quickstart`_ — create a project with Gearbox, the command-line toolkit.
- `API tutorial on GitHub (2.5.1)`_ — build a JSON API with ``gearbox quickstart-api``.
- `Agent tooling on GitHub (2.5.1)`_ — work with coding assistants using project instructions and development tools.

The `rendered documentation`_ currently describes TurboGears 2.5.0.
For release-specific guidance, browse the `2.5.1 documentation source on GitHub`_
or `download text documentation`_.
