#########
Community
#########

Ask questions, share what you are building and help improve TurboGears.

- Join the `TurboGears discussion group`_ for usage questions and community discussion.
- Explore the `TurboGears projects on GitHub`_ for framework code, tools and extensions.
- Report reproducible framework bugs in the `framework issue tracker`_.
- Suggest guide improvements in the `documentation issue tracker`_.

Include your Python and TurboGears versions, a small example and the result
you expected when asking for help. See :doc:`documentation` for guides and
:doc:`current-status` for contribution entry points.

.. _`TurboGears discussion group`: https://groups.google.com/g/turbogears
.. _`TurboGears projects on GitHub`: https://github.com/TurboGears
.. _`framework issue tracker`: https://github.com/TurboGears/tg2/issues
.. _`documentation issue tracker`: https://github.com/TurboGears/tg2docs/issues
